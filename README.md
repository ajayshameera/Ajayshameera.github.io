# Ajay Kumar A — Portfolio

A cinematic, responsive portfolio inspired by the dark/gold portfolio style in the reference image.

## Files
- `index.html` — all portfolio content and structure
- `style.css` — responsive design, animation and visual styling
- `script.js` — scroll reveal and smooth navigation

## Customize before publishing
1. Replace `your.email@example.com` in `index.html` with your email.
2. Replace the LinkedIn `href="#"` with your LinkedIn profile.
3. Replace the `AK` portrait block with your own professional photo if you want.
4. Review dates/titles and edit any wording to match your official employment records.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
You can deploy the folder on GitHub Pages, Netlify, Vercel or another static hosting provider.
